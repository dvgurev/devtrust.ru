# DevTrust: Основные компоненты и страницы

## Основные компоненты системы

### 1. Аутентификация и авторизация
Регистрация/вход по email, верификация, восстановление пароля, ролевая модель (пользователь/админ/владелец), middleware защита маршрутов.

### 2. Организации и команды
Создание/управление организациями, приглашение участников, роли (OWNER/ADMIN/MEMBER), переключение между организациями.

### 3. Каталог приложений
Категории приложений, поиск/фильтрация, детальные страницы, скриншоты, описания, отзывы, рейтинги.

### 4. Подписки и биллинг
Тарифные планы (бесплатные/платные), подписки через Stripe, управление платежными методами, счета, промокоды.

### 5. Панель управления
Обзор активных подписок, управление доступом сотрудников, мониторинг использования, уведомления.

### 6. Административная панель
Управление приложениями, модерация отзывов, управление пользователями/организациями, аналитика, промо-акции.

### 7. Блог и документация
Статьи, новости, API документация, FAQ, руководства пользователя.

### 8. Система отзывов
Оценка приложений, текстовые отзывы, ответы разработчиков, модерация контента.

### 9. Установка приложений
Автонастройка поддоменов, provisioning ресурсов, SSO интеграция, управление доступом.

### 10. Аудит и безопасность
Логирование действий, защита от атак, rate limiting, валидация данных.

## Страницы и их функционал

### Публичные страницы
- **Главная** (`/`) — приветствие, рекомендованные приложения, категории, CTA
- **Каталог** (`/catalog`) — сетка приложений, фильтры, поиск, сортировка
- **Приложение** (`/apps/[slug]`) — детали, скриншоты, тарифы, отзывы, кнопка покупки
- **Покупка** (`/apps/[slug]/buy`) — выбор тарифа, промокод, оформление, Stripe Checkout
- **Блог** (`/blog`) — список статей, фильтрация, пагинация, RSS
- **Статья** (`/blog/[slug]`) — полный текст, автор, дата, связанные материалы
- **О компании** (`/about`) — информация о платформе, команда, контакты, политики
- **Документация** (`/docs`) — руководства, API docs, FAQ
- **Контакты** (`/docs/contact`) — форма обратной связи, контактная информация

### Страницы аутентификации
- **Регистрация** (`/register`) — форма создания аккаунта, валидация, подтверждение email, рефералы
- **Вход** (`/login`) — форма входа, забыли пароль, SSO опции
- **Восстановление пароля** (`/forgot-password`, `/reset-password`) — запрос сброса, email с токеном, установка нового пароля
- **Подтверждение email** (`/verify`) — верификация email, автоматический редирект

### Защищенные страницы (требуют аутентификации)
- **Панель управления** (`/dashboard`) — обзорная панель, активные подписки, недавние действия, быстрые ссылки
- **Мои приложения** (`/dashboard/apps`) — список подключенных приложений, статус подписок, управление доступом
- **Подписки** (`/dashboard/subscriptions`) — активные/исторические подписки, детали тарифов, даты обновления
- **Биллинг** (`/dashboard/billing`) — платежные методы, история транзакций, счета, настройки автопополнения
- **Уведомления** (`/dashboard/notifications`) — системные уведомления, маркировка прочитанных, настройки
- **Профиль** (`/dashboard/profile`) — личная информация, смена пароля, настройки, реферальная статистика
- **Отзывы** (`/dashboard/reviews`) — оставленные отзывы, черновики, история модерации

### Административные страницы
- **Админ-панель** (`/admin`) — общая статистика, быстрые метрики, графики активности
- **Управление приложениями** (`/admin/apps`) — CRUD для приложений, настройка тарифов, модерация, управление скриншотами
- **Управление пользователями** (`/admin/users`) — просмотр всех пользователей, блокировка/разблокировка, редактирование ролей, активность
- **Управление организациями** (`/admin/organizations`) — список организаций, участники, статистика по подпискам
- **Аналитика** (`/admin/analytics`) — графики использования, финансовая аналитика, конверсионные метрики, экспорт отчетов
- **Аудит** (`/admin/audit`) — логи действий пользователей, фильтрация по типу события, экспорт логов
- **Управление постами** (`/admin/posts`) — CRUD для статей блога, управление категориями, планирование публикаций
- **Промо-акции** (`/admin/promo`) — создание промокодов, настройка скидок, отслеживание использования
- **Управление отзывами** (`/admin/reviews`) — модерация отзывов, ответы от имени разработчиков, удаление спама

## Технологический стек
- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind CSS
- **Backend**: Next.js API Routes, Prisma ORM
- **База данных**: PostgreSQL, Redis (кэш)
- **Хранение файлов**: MinIO (S3-совместимое)
- **Аутентификация**: NextAuth.js
- **Платежи**: Stripe
- **Мониторинг**: Sentry
- **Контейнеризация**: Docker, Docker Compose

## Архитектура
Монолитная архитектура с монорепозиторием:
- `apps/web` — основной веб-интерфейс магазина
- `packages/core` — общие утилиты и типы
- `packages/app-template` — шаблон для разработчиков приложений
- `design-system` — дизайн-система и компоненты

## Бизнес-процессы
1. **Покупка приложения**: выбор → тариф → промокод → Stripe Checkout → подписка → доступ
2. **Установка приложения**: активация подписки → создание поддомена → SSO настройка → доступ пользователям
3. **Реферальная система**: уникальный код → приглашения → бонусы за регистрации → оплата подписок бонусами

## Безопасность
- Аутентификация (NextAuth с сессиями)
- Авторизация (ролевая модель, middleware)
- Валидация данных (Zod)
- Rate limiting
- SQL injection protection (Prisma)
- XSS protection, CSP headers
- CSRF protection (Next.js)
- Аудит (логирование действий)
- Шифрование (bcrypt, HTTPS)
