## Список необходимых исправлений

### 1. Компонент каталога (`catalog-client.tsx`)

#### 1.1. Мобильные категории (горизонтальный скролл)
- **Проблема**: На очень маленьких экранах (320px) кнопки категорий могут обрезаться
- **Решение**: Добавить `min-width` для контейнера или уменьшить padding
- **Приоритет**: Средний
- **Файл**: `apps/web/src/components/catalog-client.tsx:199-223`

#### 1.2. Поисковая строка на мобильных
- **Проблема**: При открытой клавиатуре на iOS поле поиска может скрываться
- **Решение**: Добавить `@supports (-webkit-touch-callout: none)` для iOS-specific стилей
- **Приоритет**: Низкий
- **Файл**: `apps/web/src/components/catalog-client.tsx:163-181`

#### 1.3. Карточки приложений на очень маленьких экранах
- **Проблема**: На экранах 320px карточки в 1 колонку имеют слишком маленькие отступы
- **Решение**: Увеличить `gap` для мобильных: `gap-4` вместо `gap-3`
- **Приоритет**: Средний
- **Файл**: `apps/web/src/components/catalog-client.tsx:242`

### 2. Шапка приложения (`app-header.tsx`)

#### 2.1. Мобильное меню на высоких экранах
- **Проблема**: На устройствах с высоким разрешением (iPhone Pro Max) меню может не занимать всю высоту
- **Решение**: Использовать `min-height: 100dvh` вместо `h-screen`
- **Приоритет**: Средний
- **Файл**: `apps/web/src/components/app-header.tsx` (нужно найти мобильное меню)

#### 2.2. Иконка корзины на мобильных
- **Проблема**: Touch target меньше 44x44px
- **Решение**: Увеличить padding: `p-3` вместо `p-2`
- **Приоритет**: Высокий (accessibility)
- **Файл**: `apps/web/src/components/app-header.tsx` (поиск по ShoppingCart)

#### 2.3. Поиск с autocomplete на мобильных
- **Проблема**: Результаты поиска могут выходить за границы экрана
- **Решение**: Добавить `max-width: 100vw` и `left: 0` для dropdown
- **Приоритет**: Средний
- **Файл**: `apps/web/src/components/app-header.tsx` (компонент поиска)

### 3. Главная страница (`page.tsx`)

#### 3.1. Герой-секция на очень маленьких экранах
- **Проблема**: Заголовок `text-4xl md:text-6xl` на 320px может создавать переносы строк
- **Решение**: Добавить `text-3xl` для `max-width: 375px`
- **Приоритет**: Низкий
- **Файл**: `apps/web/src/app/page.tsx:113`

#### 3.2. Сетка преимуществ на планшетах
- **Проблема**: На 768px используется 2 колонки, но контент может быть тесным
- **Решение**: Для `768px-1023px` использовать `gap-8` вместо `gap-6`
- **Приоритет**: Низкий
- **Файл**: `apps/web/src/app/page.tsx:169`

#### 3.3. Кнопки CTA на мобильных
- **Проблема**: Кнопки имеют `w-full sm:w-auto`, что на очень широких мобильных (414px) выглядит неоптимально
- **Решение**: Использовать `w-full md:w-auto` для лучшего контроля
- **Приоритет**: Средний
- **Файл**: `apps/web/src/app/page.tsx:123-137`

### 4. Недостающий функционал на мобильных версиях

#### 4.1. Фильтры в каталоге скрыты на мобильных
- **Проблема**: Боковая панель с фильтрами полностью скрыта на мобильных (`lg:hidden`), пользователи не могут фильтровать приложения
- **Решение**:
  1. Создать мобильное модальное окно с фильтрами
  2. Добавить кнопку "Фильтры" в мобильном интерфейсе
  3. Перенести важные фильтры (категории, сортировка) в верхнюю панель
- **Приоритет**: Высокий
- **Файл**: `apps/web/src/components/catalog-client.tsx:114-156`

#### 4.2. Отсутствие сравнения приложений на мобильных
- **Проблема**: Функция сравнения приложений может быть недоступна или скрыта на мобильных
- **Решение**:
  1. Создать упрощенный интерфейс сравнения для мобильных
  2. Добавить возможность сравнения через swipe-жесты
  3. Реализовать модальное окно для сравнения
- **Приоритет**: Средний
- **Файлы**: Страница сравнения (`/compare`)

#### 4.3. Ограниченный функционал админ-панели на мобильных
- **Проблема**: Сложные таблицы и инструменты администрирования могут быть неудобны на мобильных
- **Решение**:
  1. Создать мобильную версию админ-панели с карточками вместо таблиц
  2. Вынести ключевые действия в floating action button
  3. Упростить формы ввода для мобильных
- **Приоритет**: Средний
- **Файлы**: Все админские компоненты (`/admin/*`, `/dashboard/*`)

#### 4.4. Отсутствие мобильной версии для сложных форм
- **Проблема**: Формы с множеством полей (регистрация организации, настройки) не адаптированы для мобильных
- **Решение**:
  1. Разбить длинные формы на несколько шагов (wizard)
  2. Использовать нативные элементы ввода на мобильных
  3. Добавить autocomplete и упрощенную валидацию
- **Приоритет**: Средний
- **Файлы**: Формы регистрации, настройки профиля, создание организации

### 5. Общие проблемы адаптивности

#### 5.1. Отсутствие контейнера для очень широких экранов
- **Проблема**: На экранах 4K+ (3840px) контент растягивается слишком широко
- **Решение**: Добавить `max-width: 1920px` и `margin: 0 auto` для контейнеров
- **Приоритет**: Низкий
- **Файлы**: Все компоненты с `container mx-auto`

#### 5.2. Изображения без адаптивности
- **Проблема**: Некоторые изображения могут не иметь `max-width: 100%`
- **Решение**: Добавить глобальный стиль `img { max-width: 100%; height: auto; }`
- **Приоритет**: Средний
- **Файл**: `apps/web/src/app/globals.css`

#### 5.3. Таблицы на мобильных
- **Проблема**: В админ-панели таблицы могут создавать горизонтальный скролл
- **Решение**: Добавить `overflow-x-auto` для табличных контейнеров
- **Приоритет**: Средний
- **Файлы**: Админские компоненты

### 5. Accessibility проблемы

#### 5.1. Контрастность текста
- **Проблема**: `text-slate-500` на `bg-slate-50` может не соответствовать WCAG AA
- **Решение**: Проверить контрастность и использовать `text-slate-600`
- **Приоритет**: Высокий
- **Файлы**: Все компоненты

#### 5.2. Отсутствие ARIA-атрибутов
- **Проблема**: Мобильное меню не имеет `aria-expanded` и `aria-controls`
- **Решение**: Добавить ARIA-атрибуты для интерактивных элементов
- **Приоритет**: Высокий
- **Файл**: `apps/web/src/components/app-header.tsx`

#### 5.3. Keyboard navigation
- **Проблема**: Фокус может теряться при закрытии модальных окон
- **Решение**: Реализовать trap focus для модальных окон
- **Приоритет**: Средний
- **Файлы**: Все модальные компоненты

### 6. Производительность на мобильных сетях

#### 6.1. Отсутствие lazy loading для изображений ниже fold
- **Проблема**: Все изображения загружаются сразу, даже те, что не видны
- **Решение**: Добавить `loading="lazy"` для всех изображений кроме LCP
- **Приоритет**: Высокий
- **Файлы**: Все компоненты с изображениями

#### 6.2. Большие размеры изображений
- **Проблема**: Изображения приложений могут быть слишком большими для мобильных
- **Решение**: Использовать `next/image` с оптимизацией под размеры экрана
- **Приоритет**: Высокий
- **Файлы**: `catalog-client.tsx`, `page.tsx`

#### 6.3. Отсутствие кэширования статических ресурсов
- **Проблема**: Статические ресурсы не имеют длительного кэширования
- **Решение**: Настроить Cache-Control headers в Next.js конфигурации
- **Приоритет**: Средний
- **Файл**: `apps/web/next.config.ts`

## Рекомендации по реализации

### 1. Создать утилитарные классы
```css
/* Добавить в globals.css */
@utility touch-target {
  min-height: 44px;
  min-width: 44px;
}

@utility container-wide {
  max-width: 1920px;
  margin-left: auto;
  margin-right: auto;
}
```

### 2. Использовать CSS custom properties для breakpoints
```css
:root {
  --breakpoint-mobile: 320px;
  --breakpoint-tablet: 768px;
  --breakpoint-desktop: 1024px;
  --breakpoint-wide: 1920px;
}
```

### 3. Добавить тестовый режим адаптивности
```typescript
// Компонент для визуализации breakpoints в development
```
