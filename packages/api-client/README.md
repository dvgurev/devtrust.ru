# @devtrust/api-client

Типизированный HTTP-клиент для взаимодействия внешних приложений с платформой DevTrust.

## Возможности

- 🔐 Автоматическая подстановка сессионного токена во все запросы
- 🚀 Встроенное кэширование часто запрашиваемых данных (через Redis платформы)
- 📁 Удобная загрузка файлов с отслеживанием прогресса
- 🛡 Автоматическая проверка прав доступа перед операциями
- 📦 Полная типизация всех ответов и параметров
- 🔄 Ретрай-логика для нестабильных соединений
- 📡 Поддержка Server-Sent Events (SSE) для real-time уведомлений

## Установка

```bash
npm install @devtrust/api-client
# или
pnpm add @devtrust/api-client
