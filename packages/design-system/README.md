# @devtrust/design-system

Базовая дизайн-система платформы DevTrust. Набор атомарных UI-компонентов,
токенов и стилей, обеспечивающих единый визуальный язык для платформы
и всех подключаемых приложений.

## Философия

Дизайн-система DevTrust построена на принципах:

- **Атомарность** — каждый компонент делает что-то одно, но хорошо
- **Композиция** — сложные интерфейсы строятся из простых блоков
- **Доступность** — все компоненты соответствуют WCAG 2.1 AA
- **Темизация** — светлая и тёмная темы из коробки
- **Нулевая бизнес-логика** — никаких запросов к API или проверок прав
