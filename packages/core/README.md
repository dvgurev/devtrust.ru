# @devtrust/core

Фундаментальный пакет платформы DevTrust. Содержит общие типы, утилиты,
сервисы и React-компоненты, используемые как самой платформой, так и
всеми внешними подключаемыми приложениями.

## Что внутри?

- 🔐 **SSO-авторизация** — управление сессиями, JWT-токены, middleware
- 🛡 **RBAC-права** — детальная система прав и ролей
- 🚀 **Кэширование** — Redis-хелперы для быстрого доступа к данным
- 📁 **Хранилище** — S3/MinIO-клиент с presigned URL
- 🎨 **UI-обёртки** — `AppShell`, `Can`, `useSession` для внешних приложений
- 📦 **Типы** — все общие интерфейсы и контракты

## Установка

```bash
npm install @devtrust/core
# или
pnpm add @devtrust/core
