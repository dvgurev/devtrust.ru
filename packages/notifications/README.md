# @devtrust/notifications

Единый сервис уведомлений платформы DevTrust. Предоставляет каналы
доставки (in-app, email, WebSocket, push) и единый API для отправки
уведомлений из любого подключённого приложения.

## Что это?

Вместо того чтобы каждое приложение само подключало SendGrid, Firebase
или WebSocket-сервер, платформа предоставляет готовый сервис. Приложению
достаточно вызвать один метод — платформа сама доставит уведомление
по всем нужным каналам с учётом настроек пользователя.

## Возможности

- 📬 **In-app уведомления** — колокольчик в интерфейсе
- 📧 **Email** — через общий шаблонизатор
- 🔔 **WebSocket / SSE** — реальное время
- 📱 **Push-уведомления** — браузерные и мобильные (на будущее)
- 🎛 **Настройки каналов** — пользователь выбирает, куда получать
- 📦 **Группировка** — объединение однотипных уведомлений
- 🔇 **Batching** — накопление и отправка дайджестом
- 📊 **Логирование** — полная история отправки и прочтения

## Быстрый старт

### 1. Отправка уведомления из приложения

```typescript
import { DevTrustClient } from '@devtrust/api-client';

const client = new DevTrustClient({
  baseUrl: 'https://mycompany.devtrust.ru',
  sessionToken: token,
  appId: 'task-manager',
});

// Простое уведомление
await client.notifications.send({
  userId: 'user-456',
  template: 'task.assigned',
  data: {
    taskTitle: 'Обновить дизайн лендинга',
    taskId: 'task-789',
    assignedBy: 'Иван Петров',
  },
  actionUrl: '/tasks/789',
});
