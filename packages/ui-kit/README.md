# @devtrust/ui-kit

Библиотека бизнес-компонентов платформы DevTrust. Надстройка над
`@devtrust/design-system`, использующая `@devtrust/core` для работы
с сессиями, правами, файлами и уведомлениями.

## Что это?

Если `design-system` — это атомарные компоненты (кнопки, инпуты, модалки),
то `ui-kit` — это готовые молекулы и организмы, решающие конкретные
бизнес-задачи платформы. Все компоненты используют хуки и типы из `core`.

## Возможности

- 👤 **UserAvatar** — аватар пользователя с данными из сессии
- 🛡 **PermissionGate** — обёртка, скрывающая контент без прав
- 📁 **FileUploader** — загрузка файлов с прогрессом и превью
- 🔔 **NotificationBell** — колокольчик уведомлений с бейджем
- 📋 **AppNavigation** — боковое меню, строящееся из AppManifest
- 📊 **DataTable** — таблица с сортировкой, фильтрацией и пагинацией
- 📝 **AuditLogViewer** — просмотр журнала аудита
- 💳 **PlanBadge** — отображение текущего тарифного плана
- 🔍 **SearchModal** — модальное окно глобального поиска
