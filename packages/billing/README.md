# @devtrust/billing

Сервис управления подписками, тарифами и биллингом платформы DevTrust.

## Что это?

Пакет предоставляет всё необходимое для монетизации платформы: управление тарифными
планами, подписками, trial-периодами, лимитами и счетами. Он интегрируется
с платёжными шлюзами (Stripe, ЮKassa) и предоставляет единый API как для самой
платформы, так и для внешних приложений.

## Возможности

- 💳 Интеграция с Stripe и ЮKassa
- 📊 Тарифные планы с гибкими лимитами
- 🎁 Trial-периоды и промокоды
- 📈 Управление usage-based биллингом
- 📧 Автоматические счета и квитанции
- 🔔 Уведомления о списаниях и окончании подписки
- 🛡 Проверка лимитов перед выполнением операций
- 📊 Дашборд доходов и метрик (MRR, ARPU, Churn)

## Быстрый старт

### 1. Проверка доступа по подписке

```typescript
import { BillingGuard } from '@devtrust/billing';

// В API-роуте платформы
export const createTask = BillingGuard.requireFeature('unlimited_tasks')(
  async (req, res) => {
    // Логика создания задачи
    await createTask(req.body);
    return res.json({ success: true });
  }
);
