# @devtrust/app-template

Шаблон для создания внешнего приложения платформы DevTrust.

## Что это?

Этот репозиторий — отправная точка для создания **внешнего подключаемого приложения**,
которое живёт в собственном репозитории, независимо собирается и деплоится,
а затем загружается платформой DevTrust во время выполнения.

## Возможности из коробки

- 🏗 Готовая структура проекта на TypeScript + React
- 📦 Сборка в UMD-бандл для динамической загрузки платформой
- 🔐 Интеграция с SSO платформы через `@devtrust/core` (компонент `AppShell`)
- 🛡 Проверка прав доступа через `@devtrust/api-client`
- 🎨 Использование общей дизайн-системы (`@devtrust/design-system`)
- 🧩 Пример манифеста приложения (`AppManifest`)
- 🚀 Готовый CI/CD-шаблон для публикации бандла

## Требования

- Node.js >= 18
- pnpm >= 8
- Доступ к приватному NPM-реестру DevTrust (GitHub Packages)

## Быстрый старт

### 1. Создание нового приложения из шаблона

```bash
# Клонируем шаблон
git clone https://github.com/dvgurev/devtrust-app-template.git my-app
cd my-app

# Устанавливаем зависимости
pnpm install

# Запускаем локальный дев-сервер
pnpm dev
